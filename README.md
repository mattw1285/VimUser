# VimUser

_A centralised repo of my personal config files and env setup._

## Overview

This repo started life as `MyConfig`, encapsulating current purpose and OS configuration.
It became increasingly clear that these were two seperate tasks.
As such, I've devolved my work into two seperate repos, `VimUser` and `FlashGordon`.
`MyConfig` is now defunct and renamed.

This repo is a centralised repo for my personal config files and env setup. 
The goal is to minimise repetitive manual steps, automate common tasks and maintain a reproducible baseline.
On a practical level, this essentially places focus on dotfiles.

My choices are intentionally opinionated and personal. 
This is not meant to be universal, but rather my evolving toolkit for personal projects.
